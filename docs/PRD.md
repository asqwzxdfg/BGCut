# BGCut - 이미지 배경 제거 서비스 PRD

## 1. 제품 개요

### 1.1 제품명
**BGCut**

### 1.2 제품 목적
사용자가 업로드한 이미지의 배경을 자동으로 투명하게 변환하여 PNG 형식으로 다운로드할 수 있는 웹 서비스

### 1.3 타겟 사용자
- 쇼핑몰 운영자 (상품 이미지 편집)
- 디자이너 (빠른 배경 제거 필요 시)
- 일반 사용자 (SNS용 이미지, 프로필 사진 등)
- 마케터 (광고 소재 제작)

### 1.4 핵심 가치
- 무료로 빠르게 이미지 배경 제거
- 회원가입 없이 즉시 사용 가능
- 다중 이미지 일괄 처리 지원

## 2. 페이지 구조

### 2.1 단일 페이지 구성 (SPA)
BGCut은 단일 페이지 애플리케이션으로, 모든 기능이 하나의 페이지에서 이루어짐

#### 페이지 레이아웃 섹션
```
┌─────────────────────────────────────────────────────────┐
│                      Header                             │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                   Hero Section                          │
│              (서비스 소개 텍스트)                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                 Upload Section                          │
│            (드래그앤드롭 / 파일선택)                      │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                 Result Section                          │
│     (업로드 후 표시 - 원본/결과 비교 및 다운로드)          │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                      Footer                             │
└─────────────────────────────────────────────────────────┘
```

|------|------|

```
┌─────────────────────────────────────────────┐
│  [썸네일]  파일명.jpg                        │

```

| 항목 | 상세 |
|------|------|

| 상태 텍스트 | "대기 중" / "처리 중..." / "완료" / "실패" |

#### 3.4.3 처리 상태별 스타일
| 상태 | 프로그레스 바 | 상태 텍스트 | 추가 요소 |

| 처리 중 | 강조색, 애니메이션 | "처리 중..." | 스피너 아이콘 |
| 완료 | 성공색 (녹색), 100% | "완료" | 체크 아이콘 |

## 4. 인터랙션 및 애니메이션 요구사항

### 4.1 버튼 상태
| 상태 | 시각적 변화 |
|------|-------------|
| Default | 기본 스타일 |
| Hover | 밝기 변화 또는 그림자 추가, 커서 pointer |
| Active/Pressed | 살짝 눌린 느낌 (scale 축소 또는 색상 변화) |
| Disabled | 투명도 감소 (opacity 50%), 커서 not-allowed |
| Loading | 스피너 표시, 텍스트 "처리 중..." 변경 |

| 드래그 이탈 | 원래 상태로 전환 (0.2s ease) |
| 파일 드롭 | 살짝 bounce 효과 |

### 4.3 결과 카드 애니메이션
| 상황 | 애니메이션 |
|------|------------|
| 카드 등장 | fade-in + slide-up (0.3s) |
| 카드 삭제 | fade-out + scale-down (0.2s) |
| 호버 | 살짝 위로 이동 + 그림자 강화 |

### 4.4 프로그레스 바 애니메이션
| 상황 | 애니메이션 |
|------|------------|
| 진행 중 | 부드러운 너비 전환 (transition) |
| 완료 | 체크 아이콘 팝업 효과 |

## 5. 반응형 디자인 요구사항

### 5.1 브레이크포인트
| 디바이스 | 너비 |
|----------|------|
| Mobile | < 768px |
| Tablet | 768px - 1024px |
| Desktop | > 1024px |

### 5.2 레이아웃 변화

#### Desktop (> 1024px)
- 결과 카드: 한 줄에 4개
- 업로드 영역: 넓은 가로 형태

#### Tablet (768px - 1024px)
- 결과 카드: 한 줄에 2-3개
- 업로드 영역: 동일

#### Mobile (< 768px)
- 결과 카드: 한 줄에 1-2개
- 업로드 영역: 세로로 더 길게
- 버튼: 전체 너비로 확장
- 텍스트: 크기 축소

## 7. 접근성 요구사항

### 7.1 키보드 네비게이션
- 모든 버튼 Tab 키로 접근 가능
- Enter/Space로 버튼 활성화
- Escape로 모달 닫기

### 7.2 스크린 리더 지원
- 모든 이미지에 적절한 alt 텍스트
- 버튼에 명확한 aria-label
- 처리 상태 변경 시 aria-live 알림

### 7.3 시각적 접근성
- 색상 대비 WCAG AA 기준 충족
- 포커스 상태 명확히 표시
- 색상만으로 정보 전달하지 않음 (아이콘/텍스트 병행)

---

## 8. 기술 스택 (권장)

### 8.1 프론트엔드
- React + TypeScript
- Vite (빌드 도구)
- TailwindCSS 또는 CSS Modules (스타일링)

### 8.2 배경 제거 처리
- 클라이언트 사이드: @imgly/background-removal (브라우저에서 직접 처리)
- 또는 서버 사이드 API 연동

### 8.3 기타 라이브러리
- JSZip (ZIP 파일 생성)
- FileSaver.js (파일 다운로드)
